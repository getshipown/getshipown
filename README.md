# Shipown

**Ship it. Own it.** Shipown is a desktop app that deploys your apps to servers you already own, over SSH.

It works on Windows, Linux and macOS, and it deploys to any Linux VPS or bare-metal server you control. Nothing gets installed on the server.

### What it does
- 🚀 Deploys Node apps under PM2, static sites from Nginx, and Dockerfile or Compose projects
- 🔒 Sets up HTTPS for your domain with Nginx and Certbot
- 📜 Streams build logs live, keeps versioned releases, and lets you roll back to a retained release
- 📊 Shows server vitals and gives you a live SSH terminal
- 🤖 Includes an AI terminal that uses your own Claude, OpenAI or DeepSeek key and asks your approval before each command runs
